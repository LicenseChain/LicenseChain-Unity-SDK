# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.3] - 2026-10-12

- Added Assets/LicenseChain/package.json for Unity Package Manager / OpenUPM installs.

## [1.0.2] - 2026-10-10

- Added GitHub Actions CI workflow for manifest validation (Unity Editor still required for playmode/editmode tests).
- Dependabot `github-actions` ecosystem now has a workflow file to target.

## [1.0.1] - 2026-10-10

- Relicensed public surface under Elastic License 2.0 (ELv2).
- Documented Unity Editor baseline `2022.3.7f1` LTS; runtime scripting aligns with .NET Standard 2.1 / Unity 2022.3.
- Added Dependabot for GitHub Actions.

## [1.0.0] - 2026-04-06

- Initial public SDK surface with repository documentation kit.
